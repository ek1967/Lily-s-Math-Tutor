# המורה שלי למתמטיקה

לומדת מתמטיקה אישית לכיתות ז'–ח' בתוכנית הלימודים הישראלית, בנויה סביב שלושה עקרונות:

1. **סוגרים פערים, לא רק שיעורי בית.** הנושאים מסודרים בגרף תלויות, כך שכשנתקעים —
   המערכת יודעת לאיזה נושא־קדם לחזור ולא רק חוזרת על אותו הסבר.
2. **תרגול מיידי ובאפס עלות.** התרגילים נוצרים בקוד, לא על ידי AI: תשובה מופיעה ב-0ms,
   גם בלי אינטרנט וגם בלי מפתח API.
3. **מסך אחד, משימה אחת.** מותאם ללמידה עם קשיי קשב — בלי טיימרים, בלי אדום,
   ובלי לבקש בחירה כשאפשר להחליט במקום המשתמשת.

## הרצה מקומית

```bash
npm install
npm run dev        # http://localhost:5173
```

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | שרת פיתוח |
| `npm run build` | בנייה לפרודקשן (`dist/`) |
| `npm run preview` | תצוגה מקומית של הבנייה |
| `npm run typecheck` | בדיקת טיפוסים |
| `npm test` | בדיקות (Vitest) |

## פריסה ל-GitHub Pages

הפריסה אוטומטית מהענף `main` דרך `.github/workflows/deploy.yml`, ורק אחרי
שבדיקת הטיפוסים והבדיקות עוברות.

> **צעד ידני חד־פעמי**: ב-GitHub → **Settings → Pages → Source = GitHub Actions**
> (לא "Deploy from a branch"). בלי זה ה-workflow ייכשל.

## פרטיות ועלות

- כל הנתונים — התקדמות, היסטוריה וקבצים — נשמרים **בדפדפן של המכשיר בלבד**. אין שרת.
- מפתח ה-API של Anthropic מוזן פעם אחת בהגדרות ונשמר מקומית. הוא **לא** נכנס ל-git.
- מומלץ מפתח ייעודי ב-workspace נפרד עם תקרת הוצאה חודשית בקונסולה של Anthropic.
- העלאת צילום של דף עבודה שולחת אותו ל-API של Anthropic. נדרשת הסכמת הורה מפורשת באפליקציה.
- ה-IndexedDB של Safari מפונה אחרי כ-7 ימים ללא שימוש. יש לייצא גיבוי מדי פעם ממסך ההורים,
  ולהוסיף את האפליקציה למסך הבית.
